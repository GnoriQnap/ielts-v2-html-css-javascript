# IELTS 同义替换练习

纯 HTML、CSS、JavaScript 的英语词汇语义分类训练项目。当前完成阶段 3：统一复习队列与强化模式。

## 当前功能

- 加载并验证正式 `vocabulary_list`；
- 复用阶段 0 的标准化和多分类索引；
- 从 1119 个唯一词条中随机出题；
- 每题生成 10 个不同 group_id 的分类选项；
- 单分类词使用单选交互；
- 多分类词使用多选交互，并按 group_id 集合全等判题；
- 判题后显示正确项和错误选择，并锁定选项；
- 可连续进入下一题；
- 按 wordKey 保存 new、review、remembered 学习状态；
- 保存每个词条的正确、错误、答题次数和最后答题时间；
- 使用 localStorage 恢复当前题、选项顺序、选择和判题结果；
- 答错后自动进入待强化，答对后由用户选择待强化或已记忆。
- 使用唯一的 `practice.reviewQueue` 保存自由练习复习调度；
- 待强化词在随机等待 5–7 道其他题后优先回插，重复调度只更新同一队列项；
- 支持随机模式和只测试 review 词条的强化模式；
- 强化模式没有待强化词时显示明确空状态。

## 本地运行

ES Modules 需要通过静态文件服务器打开。例如：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 自动测试

测试只使用 Node.js 内置测试器，不需要安装依赖：

```sh
npm test
```

也可以直接运行：

```sh
node --test
```

Node.js 只用于开发测试，网页部署和运行不依赖 Node.js。

## 本地存档

应用使用 localStorage 主键 `ielts_synonym_trainer_state`。刷新页面会恢复当前题和已经完成的操作。

## 当前阶段边界

当前没有固定轮次、首页统计、单词本或词库管理功能。
