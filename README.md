# IELTS 同义替换练习

纯 HTML、CSS、JavaScript 的英语词汇语义分类训练项目。当前完成阶段 1：基础答题 MVP。

## 当前功能

- 加载并验证正式 `vocabulary_list`；
- 复用阶段 0 的标准化和多分类索引；
- 从 1119 个唯一词条中随机出题；
- 每题生成 10 个不同 group_id 的分类选项；
- 单分类词使用单选交互；
- 多分类词使用多选交互，并按 group_id 集合全等判题；
- 判题后显示正确项和错误选择，并锁定选项；
- 可连续进入下一题。

## 本地运行

ES Modules 需要通过静态文件服务器打开。例如：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 自动测试

测试只使用 Node.js 内置测试器，不需要安装依赖：

```sh
npm test
```

也可以直接运行：

```sh
node --test
```

Node.js 只用于开发测试，网页部署和运行不依赖 Node.js。

## 当前阶段边界

刷新页面会重置当前题。当前没有 localStorage、学习状态、答题统计、复习队列、强化模式、固定轮次、单词本或词库管理功能。
