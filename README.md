# IELTS 同义替换练习

纯 HTML、CSS、JavaScript 的英语词汇语义分类训练项目。当前只完成阶段 0：项目初始化与词库数据验证。

## 当前功能

- 加载正式 `vocabulary_list` 数据；
- 为词条生成只用于匹配的标准化 `wordKey`；
- 建立 `wordKey → 原始显示文本`、`wordKey → 全部 group_id` 和 `group_id → 分类` 索引；
- 检查分类、词条、重复数据和 10 选项可行性；
- 在浏览器诊断页展示汇总、问题及多分类词条抽样。

## 本地查看

ES Modules 需要通过任意静态文件服务器打开。例如系统安装了 Python 时，在项目目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 测试

测试只使用 Node.js 内置测试器，不需要安装依赖：

```sh
npm test
```

也可以直接运行：

```sh
node --test
```

Node.js 只用于开发测试，网页部署和运行不依赖 Node.js。

## 数据验证基线

- 原始词条归属：1178
- 唯一词条：1119

- 警告：分类 1“表明观点”中的 `report` 重复出现一次

当前重复只作为数据警告。索引按 wordKey 去重分类归属，并保留第一次出现的原始显示文本。

## 阶段边界

当前没有答题、学习状态、localStorage、复习队列、固定轮次、单词本或词库管理功能。这些内容将在对应阶段逐步增加。
